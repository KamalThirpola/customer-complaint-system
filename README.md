# AI-Powered Customer Complaint Management System

## Overview
This project is an AI-powered Customer Complaint Management System for the pharmaceutical manufacturing industry. It helps users submit complaints, upload supporting documents, analyze complaints using AI, assess risk levels, and interact with an AI assistant.

## Features
- Submit customer complaints
- Upload complaint documents
- AI-powered complaint analysis using Google Gemini
- Risk assessment
- AI chatbot for complaint-related questions
- FastAPI backend
- React frontend

## Tech Stack
- Frontend: React.js
- Backend: FastAPI (Python)
- AI: Google Gemini API
- HTTP Client: Axios

## Project Structure

## Installation

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
